# Security policy

## Reporting a problem with these tools

If a tool gives a wrong result, or could harm a system it checks, please
report it.

1. Open an issue on this repository. Say which tool, which version (shown in
   the output header or the script) and what happened.
2. Include the output line or block, with private details removed.
3. If the problem could help an attacker, do not post details in public.
   Ask in an issue for a private contact first.

A wrong PASS is the most serious kind of problem, because it can leave a
broken server unfixed. Please report those first.

## Reporting a problem with PHP itself

These tools only check for known bugs. To report a new bug in PHP, follow
the PHP project's own security process, not this repository.
